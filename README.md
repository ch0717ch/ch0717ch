## 무엇을 하는 사람인가

- **본업은 HRD입니다.** 기업교육 과정을 기획하고, 강사를 섭외하고, 만족도를 분석해 다음 과정에 반영합니다.
- **그래서 만드는 것도 그쪽입니다.** 설문 시스템, 데이터 수집 파이프라인, 사내 자동화 도구 같은 것들입니다.
- **직접 씁니다.** 만든 도구를 실제 업무에 굴려보고, 안 맞으면 고칩니다. 데모로 끝내지 않습니다.
- **문서를 남깁니다.** 왜 그렇게 만들었는지, 무엇이 안 됐는지까지 저장소에 적어둡니다.
