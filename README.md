## 무엇을 하는 사람인가

- **대학생입니다.** 전공 공부와 병행해서 필요한 도구를 직접 만들어 씁니다.
- **실제로 겪은 불편에서 시작합니다.** 수강신청 시간표, 인턴 때 맡았던 교육 만족도조사,
  손으로 갱신하던 기업 데이터 — 전부 제가 직접 부딪힌 문제입니다.
- **만들고 끝내지 않습니다.** 직접 굴려보고 안 맞으면 고칩니다. 데모로 두지 않습니다.
- **문서를 남깁니다.** 왜 그렇게 만들었는지, 무엇이 안 됐는지까지 저장소에 적어둡니다.
